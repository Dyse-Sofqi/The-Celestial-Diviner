## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 注释区公告支持加粗

- 公告里的 `**文本**` 现在渲染为**加粗**（此前原样显示星号）；加粗可以包裹超链接（`**[文本](链接)**`）
- 其余规则不变：`[文本](链接)` 与裸 URL 仍渲染为可点击超链接；未闭合的 `**` 原样显示不误伤
- 注意：公告由程序启动时远端同步渲染——**只有升级到本版本才能看到加粗**，旧版本会把星号原样显示出来

## 改进 · 「成为衍天/莫问高手」激活态加粗

- 底栏按钮激活后除金色墨迹外**字体同步加粗**，一眼可辨；关闭后恢复常规字重

## 上个版本回顾 · 注释区文本可选中复制（v1.8.3）

- 左下注释区的公告与悬停说明文本都可以选中复制：拖动划选 → `Ctrl+C`，或右键 → 复制 / 全选

## 升级方式

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 程序内「选项」→ 检查更新 也可自动升级到本版本（发现新版本时该项亮红点，底栏同时出现「有更新」）
