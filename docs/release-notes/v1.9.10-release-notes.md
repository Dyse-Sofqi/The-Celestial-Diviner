## 本轮重点 · 语音系统：修一个「永久静音」，补一堆「说不出为什么没声音」

这一版没有新玩法，只处理提示语音。

### 一、修好「成为莫问高手」之后启动音不响

有用户反馈：莫问高手主题下按总开关，本该播「莫问糕手启动」，实际没声音，
而停止音、切换音、高松灯那一套全都正常，重启软件才恢复。

原因是**切换方案档位时会按新主题把语音整套重装一遍**。如果这一下正好撞上某段语音正在播放，
播放器会被就地关掉再重新打开；Windows 的媒体播放器在被中途关掉后会残留内部状态，
这次打开就失败了，之后这段语音一直不出声，直到下一次切主题才可能恢复。

莫问启动音恰好是唯一一个「会在播放中被重装」的语音（其他几段都是重装之后才播），
所以只有它中招——这也解释了为什么其他语音都正常。

现在：

- **目标音频没变就不重装**，不会再打断正在播放的声音
- 需要换音频时**换一个全新的播放器**，不重复使用旧的
- 万一打开失败，**250 毫秒后自动重试一次**；每次播放前再做一次自愈
- 结果是：单次失败不会再让某段语音永久哑掉

### 二、「没声音」的时候，程序会把原因说出来

以前语音不出声，界面上什么都不提示——点试听也没反应，用户只能猜。
这一版把这几种情况全部显式化：

- **语音设置窗口顶部新增警示条**，逐条列出：
  - 提示语音音量被拉到 0%
  - 系统当前没有可用的音频输出设备（蓝牙耳机断开、默认播放设备被禁用时常见）
  - 程序目录里缺少配套音频（只拿走了 exe、解压后移动了目录、被安全软件删除）
  - 已选的自定义语音文件丢失
- 下拉列表里**缺文件的配套音频直接写明缺哪个**：「默认音频（缺少 高松灯启动.mp3）」
- 点「试听」发不出声时**弹出提示说明原因**，不再点了毫无反应
- **启动时写一条「语音自检」日志**（当前主题 / 缺失项 / 音量 / 音频设备数）。
  遇到“没声音”，把 `%APPDATA%\TheCelestialDiviner\logs\app-当天.log` 发给作者，
  一条日志就能分清是缺文件、音量归零、设备问题，还是播放器打不开

### 三、顺带加固

- 内嵌启动音写入临时目录时，如果旧缓存文件被占用（安全软件扫描、残留句柄）导致写不进去，
  会改用带内容标记的备用文件名——此前这一下失败会让衍天、莫问两个启动变体一起静音

## 升级方式

- 1.9.x 用户：程序内「选项 → 检查更新」即可发现并安装 1.9.10（主通道 / 备用通道均可用）
- 也可以直接下载覆盖安装，配置（方案、热键、音量、外观）在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 配置版本不变（v22），**不做任何迁移动作**，全部设置原样保留

## 如果你现在正遇到「没有声音」

按这个顺序看三眼，基本能定位：

1. **底栏音量图标**是不是显示成静音态 / 点开看是不是 0%
2. **程序目录里**（exe 旁边，或 `audio` 子目录）有没有 `高松灯启动.mp3`、`墨提斯，启动！.wav` 这些文件
3. **语音设置**里那行的默认音频显示的是「默认音频（高松灯启动）」还是「缺少 …」

前两种自己就能修；第三种情况如果文件明明在还是不出声，请把日志发给作者。

## 已知问题

- **多宏方案 >2 键降级会被旧版清除**（沿自 1.9.6）：降级回 ≤1.9.5 前先在「选项 → 导出配置」备份
- **已设为鼠标侧键的热键在 ≤1.9.6 旧版中失效**（沿自 1.9.7）：降级需重新设置为键盘键
- **Toggle（点按切换）自环方案"按下被吞"**（沿自 1.9.5）：队列深时 Toggle 键的按下可能被
  当成回环吞掉，表现为"点了没反应"；遇到时切一次注入模式或重启可恢复
- **Win11 25H2 上个别用户反馈 DD 驱动"触发按键后运行几秒自动停止"**（沿自 1.9.4）。
  遇到时请把日志发给作者；影响使用可先改用 Interception
