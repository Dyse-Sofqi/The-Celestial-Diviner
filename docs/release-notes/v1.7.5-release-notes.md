## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 新功能

- **连发间隔上限提升至 90 秒（一分半）**：方案行内的「连发间隔」可调范围由 10~100ms 放宽到 10~90000ms，可用于慢速 / 定时触发场景（如定时补 buff）
  - 行内输入框（5 位）与悬停说明范围同步更新为 10~90000
  - 配置加载与配置导入的钳位一并放宽；超过 90000 仍按非法值处理（退回上次有效值）
- **精确模式（间隔 > 100ms）**：按压时长与连发间隔均取消 ±20% 随机抖动，按设定值精确执行、触发时刻精确——慢速连发不再局限于按键辅助场景；≤100ms 的高频连发保留抖动（规避固定节奏指纹）
- **双宏两键独立设置**：双宏开关的辅键现在也有自己的按压时长 / 连发间隔编辑框与可视化开关（eye），两键节奏可分别调整、键帽可单独控制显示；方案行首「启用 / 停用」与「首键参与连发」勾选框的悬停说明移到左下注释区展示
- **长间隔下的可视化表现**：间隔超过约 1.2 秒时，连发键帽在两次脉冲之间按原有空闲宽限淡出、下一发脉冲自动重建（仅视觉表现，注入节奏不受影响）

## 使用说明

- 解压后进入同名文件夹即可使用，请以管理员身份运行（低级键盘钩子与 DD 驱动均需要）
- 免费版 DD 驱动加载时需要联网授权一次；发布包不含闭源 DD 驱动，首次使用 DD 模式时按程序引导一键获取
- 升级不会丢失任何本地数据：方案档位、热键、音量、主题、自定义语音等全部存于 `%APPDATA%\TheCelestialDiviner\`（安装目录之外）
- 「检查更新」的更新源为 **Gitee Release**；本页附件与 Gitee 同步发布
