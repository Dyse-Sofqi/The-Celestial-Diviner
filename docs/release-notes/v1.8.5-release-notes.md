## 本轮重点 · 检查更新更可靠（限流不再被误报为"暂无 Release"）

- 有用户在 v1.8.3 点「检查更新」提示"未能从 Gitee 获取新版本"——实际 v1.8.4 早已发布，
  真正原因是 **Gitee 对匿名 API 按 IP 限流（403）**，旧版把限流静默当成了"暂无 Release"。本版修复：
- **失败原因明示**：限流（403，提示稍后再试或到 Release 页手动下载）/ 暂无 Release（404）/
  网络超时 / 返回异常，各说各话，不再笼统一句话
- **备用通道**：Release API 被限流时自动改从 Gitee raw 的 CHANGELOG.md 读取最新版本号并直连 zip 下载
  （raw 静态分发不在 API 限流体系内），API 挂了也能发现并安装更新；确认框会注明"经备用通道获取"
- **附件按名字匹配**：更新包必须形如 `TheCelestialDiviner-x.y.z-win64.zip`，不再按"第一个 .zip"挑选，
  排除 Gitee 自动附带的源码包被误选的隐患

## 升级方式

- v1.8.3 / v1.8.4 用户：本版需**手动下载覆盖安装一次**（旧版检查更新遇上限流仍会失败）；
  装上本版后，「检查更新」自带限流提示与备用通道，后续升级不再受影响
- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失

## 使用说明

- 解压后进入同名文件夹即可使用，请以**管理员身份**运行（低级键盘钩子与 DD 驱动均需要）
- 免费版 DD 驱动加载时需要联网授权一次；发布包不含闭源 DD 驱动，首次使用 DD 模式时按程序引导一键获取
- 发布包 **20 项** = exe + 依赖 dll + 7zr.exe + 配置 + **8 段候选提示音**
  （高松灯三段 / 墨提斯三段 / `02 wow.mp3` / `14 ciallo.mp3`）
