## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 修复 · 性能（本轮核心：游戏高负载下的卡顿与延迟）

- **连发启停不再排队**：按键事件在钩子线程**直通调度器**（零 UI 封送）——连发启动 / 停止、总开关热键（F9）、切换方案热键即时生效；修复游戏窗口最大化时 F9「按了没反应、连按后爆发回放」与松键停发延迟。连发任务线程改**事件等待**（去掉待机时的轮询空转）
- **键帽悬浮窗整体重构**：迁到**独立线程**（键帽呈现再忙也不拖累主窗口与连发）；**启动预显示 + 永不 Hide**（运行期零 Show / Hide / SetWindowPos——此前每次都与前台最大化的游戏做 DWM 同步阻塞 6~10 秒）；**80ms 呈现节流**（视觉更新合并应用，状态取最新、连击计数不丢）；窗口 940×180 → 560×100（单行约 7 键帽，超宽不显示的原语义不变）
- **进程级软件渲染**：游戏前台最大化时 iGPU 的 3D 队列被游戏打满（实测引擎占用 87%、DWM 仅 3%），键帽的任何 GPU 提交都排在游戏队列末尾（实测每帧等待 0.5~3.9 秒，与表面积 / 提交频率均无关）——键帽改为 **CPU 光栅化 + 内存位图上传**，呈现完全脱离 GPU 队列；另加 1×1 渲染时钟激励器兜底合成节拍
- 日志系统**异步化**（写盘移到后台线程），移除逐键「按下 / 释放」噪音日志；新增限频延迟探针（输入管线 / DD_key 注入 / 键帽渲染等，超标才记录，便于日后定位）
- 键位录入（选择态）与总开关热键的响应路径同步解耦；钩子鼠标移动事件不再逐条解析

## 升级提示

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 程序内「选项」→ 检查更新 也可自动升级到本版本
