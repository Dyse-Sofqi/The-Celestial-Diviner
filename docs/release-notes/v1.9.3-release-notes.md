本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 驱动这一层，从「能用就行」改成「能核对、能退回」

Interception 驱动挂的是系统级「键盘类过滤驱动」。它一旦注册错了，坏的不是这个软件，
而是你整块键盘和鼠标——设备管理器里一堆设备同时报 Code 39。这一版专门收拾这件事。

- **卸载不再「假成功」**：官方安装器其实同时改了**键盘类和鼠标类**，而旧版只核对键盘类。
  结果是只清掉一半也会报"卸载完成"，用户带着坏掉的鼠标继续用，还找不到原因。
  现在两个类都核对：没清干净会明确告诉你「卸载未完成：鼠标类仍残留」，卸载入口也不会跟着消失
- **装之前先预检，不让你踩进注定出事的坑**：安装前先查内存完整性（HVCI、Win11 25H2 全新安装常默认开启）/
  硬件堆栈保护 / Smart App Control、两个类上已有的第三方过滤驱动、过滤链里有没有重复项、
  与 DD 的互斥、Secure Boot、以及已知的反作弊驱动。会让键鼠失灵的机器**直接拦下并说明要关什么** ——
  开着内存完整性时那个驱动根本加载不了，而"注册进过滤链却加载不了"正是整类设备一起失灵的原因
- **装之前留底，装之后核对**：安装前把两个类的过滤链原样存一份，装完核对四件事：原有项是否还在、
  目标项是否重复、有没有空项、注册表类型是否还正常。万一安装器覆盖了你原本挂着的第三方过滤驱动
  （罗技 G HUB / 雷蛇这类），会**自动把丢的项补回去**——只补不删，不替你清理别家的东西
- **同一个驱动不会被装第二遍**：驱动已在系统里时安装入口不再出现；即使从导引或别的路径发起，
  官方安装器也不会被重复执行。重复写入是过滤链出现重复项的来源，而重复项是"设备莫名失效"的常见底料
- **新增「检查与修复驱动注册…」**（常驻在「选项 → 键盘注入」）：去掉重复项、
  按快照补回被覆盖的项、清理"注册名还在但驱动文件已经没了"的悬空项。
  它常驻是因为它要在**键鼠已经出问题**的时候还能点得到
- **开机自检**：检测到悬空项或重复项会在注释区提示一句（不弹窗、不打断），并告诉你去哪修
- **睡眠唤醒不再「看着正常但按键没反应」**：唤醒后自动重建注入上下文；
  Interception 免费版只有 10 个设备槽位，接近上限时会提示重启

## 一处措辞修正：不再推荐那三种模式

以前装不上驱动时，程序会说"可以先切到普通 / 扫描码 / 消息模式"。**这个建议对剑网三是错的** ——
这三种注入在剑网三里根本不出键，用户照着做只会白折腾一轮，还以为软件坏了。

现在统一改成如实告知：剑网三只认物理级驱动（DD / Interception），装不上时
正确做法是处理驱动问题（关掉内存完整性，或换另一条物理级路线）。三种模式仍留在菜单里，
但它们只对其它程序有效，界面上会直接写明"剑网三内不出键"。

## 排障增强

DD 与 Interception 的注入失败以前是静默的（调度器不看返回值），现场只能描述成"按键没反应"，
无法区分是驱动不再接受注入、还是连发状态被回环翻转了。现在两者都会限频记日志并带上返回码，
下次遇到问题可以直接从日志定性。

## 升级方式

- 1.9.2 用户：程序内「选项 → 检查更新」即可发现并安装 1.9.3（主通道 / 备用通道均可用）
- 也可以直接下载覆盖安装，配置（方案、热键、音量等）在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 配置版本升到 v21，新增的只是"驱动是不是本程序装的"这类记账字段，**不做任何行为迁移**

**正在用驱动（DD / Interception）的老用户，升级后行为不变：**

- 注入模式原样保留，不会被强制切换，也不会被要求重装驱动
- 已在系统里的 Interception 驱动照旧使用；程序只是多了"这套注册是否完整"的检查
- 如果检测到过滤链里有重复项或悬空项，会在注释区提示一次（不弹窗），你可以自己决定何时修

## 已知问题

- **Win11 25H2 上个别用户反馈 DD 驱动"触发按键后运行几秒自动停止"**。目前还没有足够的现场日志
  来定性，可能的方向有两个：驱动在 25H2 上不再接受注入，或回环状态机被 25H2 的输入时序踩到了边界。
  本版已补上注入失败日志，遇到时请把日志发给作者。
  如果影响使用，可以先改用 Interception 驱动（开源、需要重启）—— 它的注入往返只有 0~16ms，
  对时序问题不敏感
