## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 新功能

- **方案定制（「选项」首项，取代原「方案命名」）**：四个方案档位可命名（最多 12 字，留空用默认序号 ①②③④），并**各自绑定主题预设**（默认主题 / 衍天高手 / 莫问高手）——**切换档位即整套换肤**：模式配色、标题名称与应用图标、任务栏与托盘图标、注释区公告、键帽配色一并跟随
  - 绑定「**默认主题**」的档位可**全项定制**（绑定预设主题时不展示定制项）：**应用图标**（33 个可选：程序自带衍天 / 莫问 + 31 个门派心法图标）、**应用名**（窗口名，版本号不变）、**键帽配色**、**开关模式 / 按压模式 / 双宏第二配色**（色块 + 十六进制输入，附 24 色预设板）
  - **默认主题继承原衍天高手样式**（紫金配色 + 衍天图标），应用默认即用默认主题；「衍天高手」预设的图标改为**太玄经**
  - 注释区公告按主题取用：默认主题 / 衍天高手 → `Notice.md`，莫问高手 → `Notice2.md`
- **门派主题「莫问高手」**：开关模式 `#31CBB6`、按压模式 `#66BB4D`、双宏第二配色 `#2BE9F6`，配套门派图标与莫问公告、键帽配色 Green
- **提示音候选（语音设置）**：三行（开启 / 关闭 / 方案切换）改为**下拉列表** —— 默认音频、**程序目录里的候选音频**、已导入的自定义音频；选择即与手动「导入…」同效（复制到语音目录 + 立即生效 + 落盘）。候选音频**不集成进程序**：把 `mp3 / wav / m4a / aac / wma` 放进程序目录（exe 同目录）即可被识别，随时增删替换

## 改进

- 「选项」菜单由**向上弹出改为下拉**；贴近屏幕下缘时自动翻到上方，菜单不会跑到屏幕外
- 「导入配置 / 导出配置」移入「选项」菜单；「成为衍天高手 / 语音设置 / 切换方案设置」三个按钮的悬浮提示文案移入**左下注释区**（全应用统一：同源说明，不再有两套文案）
- 菜单项样式统一（新增动作项补齐样式，夜间模式下不再出现系统默认白底项）
- 注释区公告按主题分槽缓存与远端同步（仅公告源变化时才发起请求）
- 语音设置下拉文案精简为短名（不展示文件路径）

## 修复

- 方案定制 / 语音设置下拉：程序化刷新列表时的选择变更回调曾造成无限递归（栈溢出），已加抑制
- 语音设置下拉曾显示记录 `ToString()`（含候选音频完整路径），已修正为短名

## 使用说明

- 解压后进入同名文件夹即可使用，请以管理员身份运行（低级键盘钩子与 DD 驱动均需要）
- 免费版 DD 驱动加载时需要联网授权一次；发布包不含闭源 DD 驱动，首次使用 DD 模式时按程序引导一键获取
- **候选提示音**：发布包已附带两个候选音频（`02 wow.mp3` / `14 ciallo.mp3`，与 exe 同目录），可直接在「语音设置」的下拉里选择；也可把自己的 `mp3 / wav / m4a / aac / wma` 放进程序目录（或其中 `audio` 子目录），随时增删替换
- 升级不会丢失任何本地数据：方案档位、档位名称与外观定制、热键、音量、主题、自定义语音等全部存于 `%APPDATA%\TheCelestialDiviner\`（安装目录之外）
- 「检查更新」的更新源为 **Gitee Release**；本页附件与 Gitee 同步发布
