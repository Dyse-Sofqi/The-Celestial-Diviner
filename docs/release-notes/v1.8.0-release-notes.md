## 新增 · 单实例保护（本轮核心）

- **同一登录会话内只允许运行一个衍天高手**：重复启动时程序直接退出，并把**已在运行的窗口还原、置前**，
  不再起第二个进程；窗口已经在前台时不做任何打扰，静默退出
- 覆盖"从两个不同目录各启动一份"这种最常见的多开形态——判据与程序路径无关
- 已在运行的实例**最小化到托盘**时同样能还原置前；窗口确实找不到（正在退出等）才提示一句「已在运行」
- 上一个实例被强杀 / 崩溃退出时自动接管，不会因此再也启动不了

## 修复 · 多开引发的 DD 驱动冲突（用户反馈）

- **症状**：游戏里用着用着突然弹出 DD 的「DD install error. / 驱动安装错误.」模态框，连发随之失效，
  且该框会卡住界面直到点「确定」
- **根因**：DD 虚拟驱动服务（`dd63330`）是全局单例。两个进程各自初始化时，一方把服务置为
  "标记删除"，另一方的 `CreateServiceW` 便返回 1072，DD 随即弹框（它对 1072 不重试）
- **附带伤害**：两个进程都装低级钩子导致**按键被注入两次**；`config.json` 互相覆盖导致配置写入失败
- 单实例保护从源头消除该场景

## 升级提示

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 程序内「选项」→ 检查更新 也可自动升级到本版本（发现新版本时该项亮红点）
- 如果你此前遇到过「DD install error.」：本次更新可消除"多开"这一诱因。若**只开一个**仍然出现，
  那是另一类原因（DD 驱动服务被安全软件或游戏反作弊禁用 / 处于删除挂起），**重启一次系统**后再试；
  仍不行请把 `%APPDATA%\TheCelestialDiviner\logs\` 下的日志发给作者
