## 本轮重点 · 两个「看起来像软件坏了」的顽疾

这一版没有新玩法，修两个让用户以为"软件坏了、要重新下载"的问题：
一个是按压方案松键后连发停不下来（游戏里的观感是"最多只有 3 个键能同时连发"），
一个是程序被下载工具改名后每次开机都报「组件不完整」。

### 一 · 按压方案松键后连发停不下来

#### 你会看到的现象

- 按压（按住才连发）方案里，q/e/3/f 这类多个键**一起按住**时：要么只有部分键生效，
  要么松开之后连发停不下来，再按这个键也没反应
- 三个键一起按是正常的，四个键就出问题 —— 看起来像"最多只能同时 3 个"。
  实际是前几轮卡死残留的状态造成的错觉：干净状态下任意多个键都能一起连发、一起松开全停
- 只能按全局开关 / 重启软件恢复

#### 原因

按压自环方案（目标键 = 触发键，如 q 按住连发 q）依赖"回环名额"识别自己注入的按键。
DD 驱动的注入往返延迟（实测 80~360ms）远大于连发间隔（几十毫秒），名额队列常态排到 2 深以上：

- 你**松开按键**的那一下被队列当成"新鲜的回环"误吞 → 任务以为你还按着 → 无限连发；
- 注入与回环 1:1 锁步，位移的回环永远浮不出队列来纠正；
- 卡死期间这个键的真实按下又被按住表 / 防抖吞掉 → "按了没反应"。

事件驱动模拟验证：往返 ≥ 1.5×连发间隔（DD 必然满足）时松键 100% 卡死；
Interception（往返 0~16ms）与普通模式守恒成立、无此病。

#### 已修：释放探测兜底

按住期间，系统自动重复会持续"穿过"名额队列刷新存活信号；信号沉默 600ms 即暂停注入、
把队列排干（约一个往返 + 一个周期，上限 800ms），再监听 150ms：
有事件 = 还按着（恢复连发），静默 = 已松开（立即停止任务并清按住表，后续按下立即复活）。

只在"自环 + 物理级注入（DD）+ 往返 > 连发间隔"时启用；Interception / 普通模式自动关闭，
零节奏代价。按住期间穿过的自动重复持续刷新信号，正常使用几乎不触发探测。

### 二 · 程序被改名 / 从「缓存副本」启动，报「组件不完整」

#### 你会看到的现象

- 启动弹「程序运行所需的组件不完整或版本不匹配」，缺失文件一栏是一个
  不是 `TheCelestialDiviner.exe.config` 的名字（常见 `_.cache_.` 之类的下载缓存前缀）
- 每次开机复发，重新下载安装才恢复，下次开机又坏

#### 原因

程序靠"与主程序同名的 .config"提供组件版本重定向。某些下载工具 / 启动器会把主程序
复制成缓存名运行（桌面快捷方式、开机自启指向的就是这个副本），config 没跟着改名 →
重定向失效 → 绑定失败。缺的从来不是那九个 dll，只是这一份改名后才需要的同名 config。

#### 已修：自愈 + 自动重启

- 启动自检识别出这种场景后，**自动把带重定向的 config 复制成副本同名的 config，
  然后自动重启一次** —— 窗口直接打开，不用重新下载、不用改任何东西
- 即使那个工具每次开机又把缓存铺一遍，自愈每次都会自动跑一轮，照样直接能用
- 自动重启万一没成功（目录只读等），只弹一个"已修复，请重新打开"的轻提示
- 诊断弹窗补上「当前运行的程序 / 程序目录」两行；启动日志记录实际运行的 exe 完整路径
  （`%APPDATA%\TheCelestialDiviner\logs\`），方便定位是哪个工具在改名
- 想根治的话：把桌面快捷方式 / 开机自启改回指向原名的 `TheCelestialDiviner.exe`

## 升级方式

- 1.9.x 用户：程序内「选项 → 检查更新」即可发现并安装 1.9.5（主通道 / 备用通道均可用）
- 也可以直接下载覆盖安装，配置（方案、热键、音量、外观）在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 配置版本不变，**不做任何迁移动作**：方案、档位、热键、驱动选择全部原样保留

## 已知问题

- **Toggle（点按切换）自环方案"按下被吞"是同源疾病，本版未修**：队列深时 Toggle 键的
  按下也可能被当成回环吞掉（表现为"点了没反应"）。它与按压方案的裁决语义不同
  （穿过的 down 与自动重复不可分），暂无对应兜底；遇到时切一次注入模式或重启可恢复，
  欢迎带日志反馈
- **系统关闭了键盘自动重复的用户**：按住期间无穿过事件，释放探测会周期性运行
  （每次停发约一个往返 + 0.4s），表现为节奏性停顿；松开仍能正确停止
- **Win11 25H2 上个别用户反馈 DD 驱动"触发按键后运行几秒自动停止"**（沿自 1.9.4）。
  本版已补注入失败限频日志，遇到时请把日志发给作者；影响使用可先改用 Interception
