## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 键帽进 OBS（浏览器源，透明叠加）

- 想把键帽录进 OBS 成片？底栏**摄像机按钮**开启「键帽 Web 叠加源」（源地址自动复制）→
  OBS 添加**「浏览器」源**粘贴（宽 800 高 160）→ 键帽**透明浮在游戏画面上**，缩放摆放随意的；
  桌面键帽悬浮层照常显示，互不影响。详见注释区公告与
  [OBS 录制指南](https://gitee.com/sofqi/The-Celestial-Diviner/blob/main/docs/obs-recording.md)
- **默认关闭、纯选装**：不开它，一切与 1.8.5 相同（悬浮窗/钩子/调度器代码逐字节一致）
- **注意启动顺序**：先开衍天高手再开 OBS；OBS 源属性勾「场景激活时刷新浏览器」可自动恢复
- 录制卡顿排查三步（详见指南）：OBS 画布=输出=1080p60 → 游戏内锁帧 60 →
  游戏捕获模式下禁用 MPO（`reg add "HKLM\SOFTWARE\Microsoft\Windows\Dwm" /v OverlayTestMode /t REG_DWORD /d 5 /f` 后重启）

## 升级方式

- 1.8.5 用户：程序内「检查更新」即可发现并安装 1.8.7（主通道 / 备用通道均可用）
- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 1.8.6 不存在可用版本（发版当日已撤回），从任何 ≤1.8.5 版本升级到 1.8.7 即可
