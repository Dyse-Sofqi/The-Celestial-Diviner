## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 键帽 Web 叠加源（OBS 浏览器源，键帽透明叠加）

- 底栏新增「键帽 Web 叠加源」按钮（摄像机图标，激活为金色）：开启后本机启动
  HTTP+WebSocket 服务（仅 127.0.0.1 + 访问令牌，不经外网），OBS 添加**「浏览器」源**粘贴
  URL（自动复制到剪贴板）即可——**录制画面里键帽透明浮在游戏上**，缩放摆放到任意位置；
  屏幕上的键帽悬浮层照常显示、观感完全不变
- 透明度 / 键帽配色 / 状态提醒 / 连发脉冲与桌面悬浮层实时同源
- 源 URL 随配置持久：一次粘贴，以后只按一次按钮
- 说明：OBS 窗口捕获不支持透明通道（透明一律录成黑底），键帽透明叠加走浏览器源
  ——这是各类输入可视化工具对接 OBS 的标准做法

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失

- 解压后进入同名文件夹即可使用，请以**管理员身份**运行（低级键盘钩子与 DD 驱动均需要）
