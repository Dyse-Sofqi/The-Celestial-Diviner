## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 变更 · 连发时序（本轮核心：频率上限翻倍 + 时序精确化）

- **间隔与按压时长下限 10ms → 5ms**：最高连发频率由 50 发/秒提升到约 **100 发/秒**（周期 = 按压 + 间隔 = 10ms）。极短时序主要面向 DirectInput / DD 驱动 / 消息模式与逐帧轮询之外的场景；逐帧轮询输入的游戏在 5ms 区间大多采不到样，收益有限——请按场景取舍
- **移除 ±20% 随机时序抖动**：按压与间隔按所设值**精确触发**（原「间隔 >100ms 精确模式」语义扩展到全部间隔）
- DD 驱动模式回波名额上限按新频率同步扩容（128 → 256）；注入失败日志加 2 秒限频（5ms 连发持续失败时不再每秒刷约百行日志）

## 新增 · 检查更新红点提醒

- 启动时后台预检 Gitee 最新 Release，发现新版本时「选项 → 检查更新」菜单项**右上角亮小红点**提醒（不打扰、无弹窗）；手动检查确认已是最新后熄灭

## 升级提示

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 程序内「选项」→ 检查更新 也可自动升级到本版本（有新版本时该项会亮红点）

- 解压后进入同名文件夹即可使用，请以**管理员身份**运行（低级键盘钩子与 DD 驱动均需要）
