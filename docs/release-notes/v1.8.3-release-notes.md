## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 注释区文本可选中复制

- 左下注释区的**公告与悬停说明文本都可以选中复制了**：拖动划选 → `Ctrl+C`，
  或右键 → 复制 / 全选——**交流群号、链接地址**不必再手抄
- 公告改用只读富文本框渲染：**超链接保持直接点击打开**（衍天计算器 / 体服计算器），
  选区高亮随主题色换肤（日间紫 / 夜间金），排版与旧版一致
- 悬停说明同样可选中；DD 驱动获取进度等状态文本照常实时刷新，不受影响

## 公告 · 内容更新

- 默认主题公告新增：**体服计算器**链接、**衍天 PVE 大群**（964395691）与
  **按键 bug 反馈群**（1107120285）
- 公告走 Gitee 远端同步：旧版本启动后也会自动拿到新内容，不必为了看新公告升级

## 升级方式

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 程序内「选项」→ 检查更新 也可自动升级到本版本（发现新版本时该项亮红点，底栏同时出现「有更新」）

- 解压后进入同名文件夹即可使用，请以**管理员身份**运行（低级键盘钩子与 DD 驱动均需要）
