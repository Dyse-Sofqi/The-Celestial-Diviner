## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 新增 · 主题语音方案（本轮核心：语音随主题整套切换）

- **每个主题绑定一套语音方案**：默认主题 / 衍天高手 = 「高松灯」（`高松灯启动 / 停止 / 切换.mp3`），
  莫问高手 = 「墨提斯」（`墨提斯，启动！/ 停止！/ 切换！.wav`）。切换方案档位时在换肤的同时
  语音方案一并切换——四个档位绑不同主题，切档即整套换肤 + 整套换声
- **「语音设置」按主题独立设置**：顶部新增主题选择器（默认 = 当前主题），每个主题各自的选择相互独立；
  「默认音频」项标注该主题的配套来源（「默认音频（高松灯）」/「默认音频（墨提斯）」）；
  试听经独立播放器，任意主题可试听；编辑当前主题立即生效，编辑其他主题在切换到该主题时生效
- 配置 v17：语音方案按主题存储；旧版的全局自定义提示音自动迁移到全部三个主题（保持既有听感）

## 变更 · 基础提示音从程序中分离

- 原内嵌的启动 / 停止 / 切换三段默认音频不再打进 exe，改为散装文件随发布包分发（即「高松灯」三段，
  进「语音设置」候选列表）；配套文件被删除 / 改名时该用途静音并留日志，已导入的自定义音频不受影响
- 「成为衍天高手」按钮随主题换文案：莫问高手主题下显示「成为莫问高手」，激活时播配套
  「莫问糕手，启动！」；衍天高手启动变体仍为内嵌资源，未激活播报与激活态描边行为不变

## 升级提示

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失；
  旧版已选的自定义提示音会自动迁移到全部主题
- 程序内「选项」→ 检查更新 也可自动升级到本版本（发现新版本时该项亮红点）
