## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 两处修复

- **更新确认框支持 Markdown 渲染**：「检查更新」/ 底栏「有更新」弹出的确认框由系统消息框
  改为窗口——消息框渲染不了任何格式，更新说明的 `**加粗**` 标记此前只能原样显示。
  新确认框与「更新日志」窗口同源解析（**粗体** / `代码` / [链接](url) / 标题 / 列表），
  更新说明全文可滚动查看（旧版截断到 600 字符）；Enter 立即更新 / Esc 取消
- **OBS 浏览器源键帽永久残留修复**：浏览器源里偶发一个键帽残留不消失（Alt 最常见），
  重新按键也顶不掉，只能刷新浏览器源——页面淡出计时器重入竞态误删了重按新建的键帽
  记录所致。本轮根治，且历史遗留的残留键帽升级后**无需刷新即可自愈**

## 升级方式

- 1.8.8 用户：程序内「检查更新」即可发现并安装 1.8.9（主通道 / 备用通道均可用），
  本轮起更新确认框里的说明即是上方的排版效果
- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
