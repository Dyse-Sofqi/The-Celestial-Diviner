## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 录入反馈与键位提示——一轮「看得见」的改进

这一版没有新玩法，集中解决「软件明明在提示你、你却看不见」和「键位状态一看就懂」两类体验问题。

### 一 · 录入失败不再「无提示直接失败」

- 此前所有录入校验失败（热键被方案占用、方案键冲突、额度用尽等）只写进内部日志集合，
  界面毫无反馈——你只会觉得「点了没反应」
- 现在全部录入拒绝（三个热键的键类型与占用校验 / 多宏额度与冲突 / 常规方案冲突 /
  右键取消提示）都**同步显示在录入提示条**；热键录入失败保持录入态，直接换键重试即可，
  成功才退出

### 二 · 热键占用提示指路 + 总开关校验补齐

- 热键设置撞上已被连发方案占用的键位时，提示会**指明占用的方案档位**和解决方法
  （「请切到该档位在方案列表删除该键的方案后重试，或换用其他键位」）
- 总开关的占用校验升级为**四档位全查**（与切换方案 / 独立关闭热键一致）：
  此前其他档位里同键的方案会被总开关静默压制（热键先拦截按键，方案成死键）——
  校验只在设置时运行，已设置好的热键不受影响

### 三 · 停用方案不再从键盘区隐身

- 方案在列表里取消勾选（停用）时，键盘区对应键位显示**模式色虚线轮廓 + 模式色键名**
  （开关模式 = 主题紫、按压模式 = 主题金）并保留目标键位小字——提醒你这里设置过
- 启用方案仍是实心底色；多宏触发键位标记与总开关键黑色高亮不变，四态互不混淆

### 四 · WASD / 修饰键设置方案时的风险提醒

- 常规方案创建与多宏开关键位暂存时，若键位是 **W / A / S / D** 或**修饰键**
  （Ctrl / Shift / Alt / Win 两侧），提示条 + 日志会给出风险说明：
  - 移动键：方案触发与正常移动互相干扰；**按压模式方案按住期间会暂停所有开关模式键位**
    的连发（全局暂停规则，松开恢复）
  - 修饰键：与其他键位直接形成组合键（如 Ctrl+C），每次按下——包括组合键场合——都会触发方案
- **提醒不拦截**：方案照常创建，设置与否自行取舍。多宏触发键位是纯输出、不截获输入，
  序列里放移动键不受此限

### 五 · 文案补齐

- 切换方案 / 独立关闭热键的悬停说明与录入提示补齐「鼠标侧键 1 / 侧键 2」说明
  （侧键支持 1.9.7 已上线，说明文字未同步导致误读为不支持）

## 升级方式

- 1.9.x 用户：程序内「选项 → 检查更新」即可发现并安装 1.9.8（主通道 / 备用通道均可用）
- 也可以直接下载覆盖安装，配置（方案、热键、音量、外观）在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 配置版本不变（v22），**不做任何迁移动作**，全部设置原样保留

## 已知问题

- **多宏方案 >2 键降级会被旧版清除**（沿自 1.9.6）：降级回 ≤1.9.5 前先在「选项 → 导出配置」备份
- **已设为鼠标侧键的热键在 ≤1.9.6 旧版中失效**（沿自 1.9.7）：降级需重新设置为键盘键
- **Toggle（点按切换）自环方案"按下被吞"**（沿自 1.9.5）：队列深时 Toggle 键的按下可能被
  当成回环吞掉，表现为"点了没反应"；遇到时切一次注入模式或重启可恢复
- **Win11 25H2 上个别用户反馈 DD 驱动"触发按键后运行几秒自动停止"**（沿自 1.9.4）。
  遇到时请把日志发给作者；影响使用可先改用 Interception
