## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 三个热键支持鼠标侧键

### 你可以做什么

- **总开关 / 切换方案 / 独立关闭热键**都可以设为**鼠标侧键 1 / 侧键 2**：点击对应设置按钮进入
  录入，左键点击键鼠区鼠标栏的侧键图块即完成设置（键盘键照常可设，直接按键录入不变）
- 侧键作为总开关时在键鼠区显示黑色高亮（与键盘总开关键一致）；作为切换方案 / 独立关闭热键
  时显示灰色高亮
- 按下侧键照常触发对应功能：总开关启停（已设独立关闭热键时只负责开启）、按 ①→②→③→④
  切换方案档位、一键停止全部连发
- **总开关键补上右键取消入口**（与另外两个热键对等）：录入态右键已设置的键位图块即可清除，
  清除后总开关只能通过托盘菜单切换

### 为什么左 / 右 / 中键与滚轮不收

- **左 / 右 / 中键**：每次点击都会触发开关——设成总开关后在游戏 / 桌面点任何东西都会启停连发，
  无法正常使用；录入时会给出可读提示
- **滚轮**：只有"滚动"事件、没有抬起事件，程序的按下沿判定无法复位，第二次滚动不会生效

### 兼容性

- 配置版本 v22：热键配置新增类型字段（默认键盘），旧配置加载自动补齐，**不做任何迁移动作**，
  方案 / 热键 / 音量 / 外观全部原样保留
- ≤1.9.6 旧版程序读取 1.9.7 配置会忽略新字段（降级安全；但已设为侧键的热键在旧版中会失效，
  需重新设置为键盘键）

## 升级方式

- 1.9.x 用户：程序内「选项 → 检查更新」即可发现并安装 1.9.7（主通道 / 备用通道均可用）
- 也可以直接下载覆盖安装，配置（方案、热键、音量、外观）在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失

## 已知问题

- **多宏方案 >2 键降级会被旧版清除**（沿自 1.9.6）：从 1.9.7 降级回 ≤1.9.5 前请先在
  「选项 → 导出配置」备份
- **Toggle（点按切换）自环方案"按下被吞"**（沿自 1.9.5）：队列深时 Toggle 键的按下可能被
  当成回环吞掉，表现为"点了没反应"；遇到时切一次注入模式或重启可恢复
- **Win11 25H2 上个别用户反馈 DD 驱动"触发按键后运行几秒自动停止"**（沿自 1.9.4）。
  遇到时请把日志发给作者；影响使用可先改用 Interception
