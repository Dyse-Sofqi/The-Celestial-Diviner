## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 两处修复

- **方案列表滚动跳顶修复**：滚动右侧方案列表时偶发整表跳回顶部（v1.8.2 引入的按像素
  虚拟化滚动，与"非当前模式 / 分区的行隐藏混排"的列表组织冲突所致）。本轮回归按项
  虚拟化，滚动位置稳定不跳；v1.8.2 的列表性能优化全部保留
- **键帽显示优化（桌面 / OBS 浏览器源同步）**：
  - 大写键键帽缩写为 **Caps**（与主界面键位图块一致）
  - OBS 浏览器源**键帽宽随内容自适应**（对齐桌面悬浮层）：Backspace / 小键盘 Enter 等
    长键名不再换行溢出键帽
  - OBS 浏览器源**连击角标不再被画布边缘裁切**（源右缘预留外凸余量）；画布高度 ≥96
    即可完整显示，推荐仍为 800×160（见 [OBS 录制指南](https://gitee.com/sofqi/The-Celestial-Diviner/blob/main/docs/obs-recording.md)）

## 升级方式

- 1.8.7 用户：程序内「检查更新」即可发现并安装 1.8.8（主通道 / 备用通道均可用）
- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失

## 使用说明

- 解压后进入同名文件夹即可使用，请以**管理员身份**运行（低级键盘钩子与 DD 驱动均需要）
- 免费版 DD 驱动加载时需要联网授权一次；发布包不含闭源 DD 驱动，首次使用 DD 模式时按程序引导一键获取
- 发布包 **20 项** = exe + 依赖 dll + 7zr.exe + 配置 + **8 段候选提示音**
  （高松灯三段 / 墨提斯三段 / `02 wow.mp3` / `14 ciallo.mp3`）
