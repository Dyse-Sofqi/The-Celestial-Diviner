## 本轮重点 · 开与关可以分家了

- **新增「独立关闭热键」（默认空键位）**：底栏「全局开关热键设置」右侧多了这一项。
  不设置时**行为完全照旧**——全局开关热键一键启停；一旦设置，职责就分开：
  **全局开关热键只负责开启**，关闭统一交给**独立关闭热键**。想开的时候再也不会
  一按就变成关，两个动作各归各的键
  - 已开启时按开启键不会重复开启（日志提示"关闭请按 [X]"）；已关闭时按关闭键也不会
    重复播报关闭语音
  - **想还原很简单**：点进独立关闭热键的录入，**右键已设置的那个键位**即可清空，
    回到空键位，全局开关热键立刻恢复"统一键位启停"（和「切换方案设置」的取消方式一致）
  - 键位互斥校验齐全：不能与全局开关热键、切换方案热键、任一档位的连发键撞车
    （四个档位全查），撞了会在日志里说明被谁占用了
- **左侧键盘区一眼看出键位归属**：全局开关热键仍是**黑底**；切换方案热键、独立关闭热键
  改为**中灰底**（日间 `#6E6E6E` / 夜间 `#555555`），与黑底形成明显的灰度差。
  此前切换方案热键的键位没有任何底色，容易被忘记；改键 / 取消后底色即时刷新

## 升级方式

- 1.8.9 用户：程序内「检查更新」即可发现并安装 1.9.0（主通道 / 备用通道均可用）
- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失；
  独立关闭热键属新增配置项，旧配置读入后默认为空键位，不会改变现有手感
