## 修复 · 已是最新版本时「检查更新」仍挂小红点

- **症状**：启动后即使已是最新版，菜单里「检查更新」也一直亮着红点，必须点一次检查、确认"已是最新"才消失
- **根因**：红点状态的字段没初始化，而 `Visibility.Visible == 0`——红点**默认就是亮的**；启动后台预检只在
  "发现新版本"时点亮，没有新版本时并不熄灭，于是默认值一直留着
- **现在**：红点默认熄灭，只由"确认存在更新的版本"点亮；已是最新 / 远端不可用时保持熄灭

## 修复 · DD 驱动缺失时「键盘注入 → DD 驱动」仍可选中

- **症状**：驱动没装成功时该项仍可点选，点了却回退普通模式再弹下载确认，形同"可选却选不上"
- **现在**：可加载的 x64 `dd63330.dll` 不在位时整行灰显不可选；菜单里补了「获取 DD 驱动…」入口
  （仅缺失时出现），否则就没有重新发起下载的地方了

## 修复 · 手动放入 dd63330.dll 后 DD 模式仍不可用（且毫无提示）

- **症状**：按 README 从官网手动下载放进程序目录，重启后 DD 模式依然用不了，界面上没有任何说明
- **根因**：DD 官方按位数分包，32 位那份在 64 位进程里加载必失败（错误 193）；而失败原因原先只写进日志文件
- **现在**：加载前先读 PE 头判位数——位数不符时明确提示"是 32 位 DLL，无法加载，请换用 x64 版"，
  并显示在左下注释区与获取确认框里；32 位占位文件也不再阻止自动获取（否则会永久卡在一个加载不了的文件上）

## 改进 · DD 驱动获取的进度与重试可感知

- 下载百分比、解包安装、第几次失败 / 多少秒后重试、成功或终止，全部实时显示在左下注释区
- 成功 8 秒、硬性失败 20 秒后提示自动消退，注释区回到公告

## 改进 · 更新入口重组

- 「选项」菜单在「检查更新」下方新增「**更新日志**」：点开可翻阅**全部历史版本**改了什么
- 底栏「语音设置」右侧新增「**有更新**」按钮：检测到新版本时出现（与小红点同源），
  点击弹出确认框展示最新版本号与更新日志，确认后自动下载安装并重启
- 注释区不再展示版本与更新提示，公告恢复为纯文案

## 改进 · 方案面板底部按钮

- 文案「从左侧键盘管理方案」→「**从左侧键盘增删按键方案**」
- 底色跟随当前模式：开关模式 = 主题紫、按压模式 = 主题金，白字加粗，与模式标签一致；悬停光标保持默认箭头

## 升级方式

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 程序内「选项」→ 检查更新 也可自动升级到本版本（发现新版本时该项亮红点，底栏同时出现「有更新」）
