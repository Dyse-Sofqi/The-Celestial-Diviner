## ⚠️ 使用范围声明

本软件仅供剑网三 PVE 环境下的按键辅助使用，请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境；在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，由此产生的一切后果由使用者自行承担。

## 本轮重点 · 界面跟手了

- **拖动窗口不再"落在光标后面"**：鼠标检测由全局低级钩子改为 **Raw Input**。低级钩子会让系统把
  每一个鼠标事件同步送进本程序、等回调返回才继续投递，实测把窗口收到的移动消息从 370~530 次/秒
  压到约 30 次/秒——窗口每秒只能更新 30 次，自然追不上光标。Raw Input 是并行通知，不插队、不节流
- **切换开关 / 按压模式不再卡顿**：方案列表改为"两种模式的行一次建好、切换只翻可见性"，
  并去掉会触发共享尺寸反复重算的 `SharedSizeGroup`。实测"点击 → 布局完成"从 **1613ms 降到 17~37ms**
- **空闲时不再有 60fps 常驻重绘**：键帽悬浮层的"渲染时钟激励器"改为按需创建（有键帽才建、键帽消失即销毁）
- **主窗口恢复 GPU 渲染**：移除进程级 `SoftwareOnly`（它把主窗口也拖进了 CPU 光栅化）；
  1ms 定时器精度也改为只在连发运行时持有，空闲恢复系统默认

## 改进 · 管理方案更顺手

- 对**已有方案**的键位**再点一次左键 = 取消**（右键仍然可用）；双宏分区再点第 1 键 = 整对取消
- 只对当前分区 / 模式下已有的方案生效，不会误删别的分区里看不见的方案
- 修复：管理态下"快速点一下空白"不退出（此前进入管理后 800ms 内的点击会被吞掉）
- 修复：左键按压方案"点一下就一直连发、再点也停不下来"（此前自注入过滤的 40ms 时间窗会吞掉真实松手）

## 改进 · 切换方案热键默认 F10

- 「切换方案热键」默认值由"未设置"改为 **F10**，装好即可用 F10 循环切换方案档位
- **不覆盖你已自定义的键位**：迁移只对从未设置过的用户生效；已设过的保持原样
- 迁移带标记，日后手动清空热键也不会被重新填回

## 其它

- 两版公告（默认主题 / 莫问高手）开头的 `---` 分隔线已删除，注释区直接显示诗句
- 鼠标方案（左 / 右 / 中 / 侧键 / 滚轮上下）语义不变，全部照常可用

## 升级方式

- 直接下载覆盖安装即可，配置（方案、热键、音量等）保存在 `%APPDATA%\TheCelestialDiviner\`，升级不丢失
- 程序内「选项」→ 检查更新 也可自动升级到本版本（发现新版本时该项亮红点，底栏同时出现「有更新」）

## 使用说明

- 解压后进入同名文件夹即可使用，请以**管理员身份**运行（低级键盘钩子与 DD 驱动均需要）
- 免费版 DD 驱动加载时需要联网授权一次；发布包不含闭源 DD 驱动，首次使用 DD 模式时按程序引导一键获取
- 发布包 **20 项** = exe + 依赖 dll + 7zr.exe + 配置 + **8 段候选提示音**
  （高松灯三段 / 墨提斯三段 / `02 wow.mp3` / `14 ciallo.mp3`）
