# OBS 录制指南：游戏画面 1:1 + 键帽透明叠加

面向"用 OBS 录制游戏 + 衍天高手键帽可视化"的场景，一次录制直接出成片。
本指南的结论均在实机（4K 屏 + 混合显卡笔记本 + 游戏窗口最大化）上踩坑验证过。

## 一、游戏画面 1:1 无黑边

游戏用"窗口最大化"时，OBS 窗口捕获的画面会带上标题栏，与画布不完全匹配（顶部黑条）。
这不影响录制性能，只影响画面匹配。按优先级三选一：

1. **游戏内显示设置切"无边框窗口"**（推荐）：客户区铺满整屏、无标题栏，OBS 画布分辨率设成
   游戏分辨率即 1:1。
2. **OBS 用「游戏捕获」源**（hook 模式）：直接抓游戏渲染帧，无视窗口边框，画质最干净
   （无鼠标指针 / 无桌面弹窗）——但见第三节 MPO 说明。
3. **显示器捕获**：抓合成后的桌面，桌面键帽悬浮层会**原生入镜**（键帽无需任何叠加源），
   且桌面复制会强制 DWM 全量合成，对悬浮层最友好；缺点是桌面弹窗也可能入镜。

**不要用独占全屏**：OBS 窗口捕获（WGC）抓不到独占全屏窗口（黑屏）。

**分辨率与帧率（负载三定律）**：

- 画布 = 输出 = **1920×1080 @ 60** 起步。4K60 合成 + 编码的像素量是 1080p60 的 4 倍，
  混合显卡机器直接超载——这是"巨额延迟"的最常见根源；
- **游戏内锁帧 60**（60Hz 屏上超出的帧率物理不可见，只换来约 1ms 输入延迟改善，
  却白白烧 ~10% GPU）；
- 游戏内 4K 分辨率对 1080p 成片零贡献，GPU 紧张时降到 2K。

编码：NVENC/AMF 硬件编码，CQP 18–22（或 CBR 15000–40000 kbps）。

## 二、键帽透明叠加（Web 叠加源 · 浏览器源）

OBS 的窗口捕获不支持透明通道（透明区域一律录成黑底），要键帽"透明浮在游戏上"，
用衍天高手内置的 **Web 叠加源**：本机起 HTTP+WebSocket 服务（仅 127.0.0.1 + 访问令牌，
不经外网），把键帽状态实时推给 OBS 的「浏览器源」渲染（CEF 原生透明背景）。

**设置步骤（一次性的）：**

1. 衍天高手底栏点亮**「键帽 Web 叠加源」按钮**（摄像机图标，激活为金色）：服务启动，
   源 URL 自动复制到剪贴板（日志里也有），形如 `http://127.0.0.1:43117/overlay?token=…`；
2. OBS 添加来源：**「浏览器」** → URL 粘贴 → 宽 800 × 高 160 → 属性里勾选
   **「场景激活时刷新浏览器」**（启动顺序颠倒时可自愈）→ 确定；
3. 键帽透明浮在游戏源上，缩放 / 摆放到任意位置。透明度、键帽配色、状态提醒、连发脉冲
   与桌面悬浮层**实时同源**。

**启动顺序**：先开衍天高手，再开 OBS。浏览器源的页面只在加载成功后才有断线重连能力，
初次加载失败（服务未就绪）会停在空白页——此时源属性里点「刷新缓存」，或靠上面的
「场景激活时刷新浏览器」自愈。

**令牌稳定性**：源 URL 含访问令牌，随配置持久——以后只按一次按钮。**不要**与本程序
共用 `%APPDATA%` 的新旧版本混跑（旧版保存配置会丢掉 Web 字段导致令牌重生成、OBS 源失效）。

**预览 / 诊断**：浏览器打开 `http://127.0.0.1:43117/overlay?token=demo` 看演示动画；
真实 URL 在普通浏览器打开可实测键帽显示与延迟（标签页标题实时显示端到端延迟毫秒数）。

## 三、卡顿排查（游戏前台 + OBS 时）

键帽数据链路已实测毫秒级（服务端发送零超时）；卡顿几乎都在渲染资源争抢。按序排查：

1. **OBS 分辨率 / 帧率**：画布 = 输出 = 1080p60（见第一节）；
2. **游戏锁帧 60**；
3. **游戏捕获模式下禁用 MPO**：游戏捕获不占 DWM，窗口化游戏会走 MPO/直扫路径绕过合成器，
   导致桌面悬浮层（分层窗口）与其它窗口被饿死（实测悬浮层停滞最长 12 秒；显示器捕获无此问题，
   因桌面复制强制 DWM 全量合成）。管理员运行后重启电脑：

   ```
   reg add "HKLM\SOFTWARE\Microsoft\Windows\Dwm" /v OverlayTestMode /t REG_DWORD /d 5 /f
   ```

   代价 ≈ DWM 每帧全量合成（4K60 实测零丢帧可扛）；收益 = 悬浮层停滞从秒级降到亚秒级直至消失。
   撤销：删除该注册表值后重启；
4. 仍紧张：游戏分辨率 4K→2K、编码器预设降一档（NVENC p6→p4）；
5. `config.json` 的 `WebOverlayMuteDesktop=true`：OBS 在线时自动隐藏桌面悬浮层
   （录制画面不受影响）——桌面键帽冻结碍眼时的眼不见心不烦开关，默认关闭。

## 四、方案对比备忘

| 方案 | 键帽入镜方式 | 透明 | 备注 |
|---|---|---|---|
| 浏览器源（Web 叠加源） | OBS 内独立渲染 | ✓ | 推荐；缩放摆放自由，与桌面互不影响 |
| 显示器捕获 | 桌面悬浮层原生入镜 | ✓ | 零配置；桌面弹窗会入镜，DWM 最友好 |
| 窗口捕获键帽窗口 | — | ✗ | 平台限制（透明录成黑底），已弃用 |
