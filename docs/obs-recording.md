# OBS 录制指南：游戏画面 1:1 + 键帽透明叠加

面向"用 OBS 录制游戏 + 衍天高手键帽可视化"的场景，一次录制直接出成片。

## 一、游戏画面 1:1 无黑边

游戏用"窗口最大化"时，OBS 窗口捕获的画面会带上标题栏，与画布不完全匹配（顶部黑条）。
这不影响录制性能，只影响画面匹配。按优先级三选一：

1. **游戏内显示设置切"无边框窗口"**（推荐）：客户区铺满整屏、无标题栏，OBS 画布分辨率设成
   游戏分辨率即 1:1。Win10/11 全屏优化下与独占全屏性能几乎无差。
2. **OBS 用「游戏捕获」源**（hook 模式）：直接抓游戏渲染帧，无视窗口边框，开销还最低；
   游戏保持窗口最大化也可以。
3. **兜底**：保持「窗口捕获」，对源按住 Alt 拖边裁掉标题栏（或右键 → 裁剪/变换）。

**不要用独占全屏**：OBS 窗口捕获（WGC）抓不到独占全屏窗口（黑屏）。

输出建议：画布分辨率 = 输出分辨率 = 游戏分辨率，60fps，编码器 NVENC/AMF 硬件编码，
码率控制 CQP 18–22（或 CBR 15000–40000 kbps）。

## 二、键帽透明叠加（Web 叠加源 · 浏览器源）

OBS 的窗口捕获不支持透明通道（透明区域一律录成黑底），所以要键帽"透明浮在游戏上"，
不走窗口捕获——衍天高手内置 **Web 叠加源**：本机起一个 HTTP+WebSocket 服务，把键帽状态
实时推给 OBS 的「浏览器源」渲染（CEF 原生支持透明背景）。屏幕上键帽悬浮层照常显示、
观感完全不变，录制画面里的键帽是透明浮动、独立缩放的。

**设置步骤（一次性的）：**

1. 衍天高手底栏点亮**「键帽 Web 叠加源」按钮**（摄像机图标，激活为金色）：
   服务启动，源 URL 自动复制到剪贴板，日志里也有——
   形如 `http://127.0.0.1:43117/overlay?token=…`
2. OBS 添加来源：**「浏览器」**（Browser Source）→ URL 粘贴刚才的地址 → 宽度建议 800、
   高度建议 160（键帽渲染在右下角，向左生长）→ 确定。
3. 键帽直接透明浮在游戏源上，缩放/摆放到任意位置即可。透明度、键帽配色、状态提醒、
   连发脉冲与桌面悬浮层**实时同源**。

**注意：**

- **整机卡顿时先调 OBS（关键）**：前台游戏 + OBS 捕获 + 编码会把 GPU/DWM 压到饱和，
  此时 OBS 预览、浏览器源键帽、桌面悬浮窗都会卡。按顺序处理：
  1. 游戏源用**「游戏捕获」**（hook 交换链，几乎不占 DWM）——不要用窗口捕获（WGC 强制
     DWM 走额外合成路径）/ 显示器捕获（整屏复制）；
  2. OBS 设置 → 高级 → 源：**关闭「浏览器源硬件加速」**，重启 OBS——CEF 改软件渲染，
     不再和游戏 + 编码器抢 GPU；
  3. 仍紧张再降编码器负载（NVENC 预设 p6→p4、输出 60fps→48/30）。
- **桌面键帽悬浮层**：录制画面键帽由浏览器源渲染，不经过本进程 WPF，不受桌面卡顿影响。
  若前台游戏 + OBS 下桌面悬浮层冻结碍事，可在 `config.json` 设 `WebOverlayMuteDesktop=true`
  ——浏览器源在线时桌面悬浮层自动隐藏（OBS 关闭恢复），零 DWM 压力（默认关闭，想看桌面键帽不动）。
- 源 URL 含访问令牌，随配置持久——以后再开只按一次按钮，OBS 源不用重配；
  只有改端口或卸载重装才需要重新粘贴。
- 浏览器源窗口内是**本地服务**（仅 127.0.0.1 + 令牌），不经过外网。
- 想在普通浏览器里预览样式：打开 `http://127.0.0.1:43117/overlay?token=demo`（demo 模式
  本地模拟按键动画，不发真实数据）。
- 排查：底栏开关开启后日志出现"监听失败"多为端口被占用（默认 43117，可在
  `%APPDATA%\TheCelestialDiviner\config.json` 的 `WebOverlayPort` 改端口后重启）。

## 三、旧方案对比（为何不用窗口捕获）

- **窗口捕获键帽窗口**：透明窗口捕出来是黑底（平台限制），不透明底板观感差——已废弃。
- **显示器捕获 + 裁剪**：整屏复制常开、弹窗会入镜，仅作应急。
- **浏览器源**：透明、缩放自由、不占用桌面、不经外网——推荐。
