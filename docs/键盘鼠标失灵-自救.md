# 键盘 / 鼠标失灵自救（装了 Interception 驱动之后）

> 适用：装或卸 Interception 驱动后，键盘或鼠标不动了，设备管理器里设备带黄色感叹号（错误代码 **39**）。
> 这不是硬件坏了 —— 是「设备类过滤驱动」的注册表项指向了一个加载不起来的驱动，
> **整个类的设备会一起失效**。下面三步按顺序试，绝大多数能当场恢复。

---

## 第 0 步：先看错误码（10 秒）

`Win + X` → 设备管理器 → 展开「键盘」/「鼠标和其他指针设备」→ 右键带感叹号的设备 → 属性：

| 错误码 | 含义 | 对应处理 |
|---|---|---|
| **39** | 过滤链指向了加载不了的驱动 | 本文全部适用 |
| **52** | 签名被拒（内存完整性 / Secure Boot） | 先跑第 2 步的命令，再关内存完整性 |
| 10 / 31 | 设备启动失败 | 先跑第 2 步，仍不行则卸载驱动重启 |

---

## 第 1 步：鼠标能动、或还有一块键盘能用

程序里点：**选项 → 键盘注入 → 检查与修复驱动注册…**

它会：去掉重复项、按安装时保存的快照补回被覆盖的过滤项、清理「驱动文件已不存在」的悬空项。
改完**重启电脑**生效。

如果修不动，点同一菜单里的 **卸载 Interception 驱动…** —— 它会调用官方安装器把两个类的注册项都摘掉（也要重启）。

---

## 第 2 步：键鼠全都动不了

**安全模式里键盘是能用的**（安全模式不加载第三方类过滤驱动），所以从那里下手：

1. 按住 **Shift** 点「重启」→ 疑难解答 → 高级选项 → 启动设置 → 重启 → 按 **4**（安全模式）
   - 老系统：开机连按 F8
2. 进安全模式后，`Win + R` → 输入 `cmd` → 按 `Ctrl + Shift + Enter`（管理员）
3. 逐条粘贴，每行回车：

```
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Class\{4D36E96B-E325-11CE-BFC1-08002BE10318}" /v UpperFilters /t REG_MULTI_SZ /d kbdclass /f
```
```
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Class\{4D36E96F-E325-11CE-BFC1-08002BE10318}" /v UpperFilters /t REG_MULTI_SZ /d mouclass /f
```

4. 正常重启。

这两条就是把键盘类、鼠标类的过滤链还原成 Windows 默认值（`kbdclass` / `mouclass`）。
**这么做之后 Interception 就没挂上了**，等于退回没有装它的状态 —— 这通常正是你想要的。

> 如果这两条也救不回来：重启进安全模式 → 设备管理器卸载带感叹号的设备（勾选"删除驱动程序软件"）→ 重启让系统重装。

---

## 第 3 步：以上都不行

- 系统还原点：`Win + R` → `rstrui` → 选装驱动之前的时间点
- 或用另一台设备把本程序目录删掉，再走第 2 步的两条命令（程序删了不影响注册表项，必须显式清）

---

## 怎么避免再来一次

1. **不要把 `C:\Windows\System32\drivers\keyboard.sys` / `mouse.sys` 手动删掉**。
   很多"反作弊提示请关闭 Interception"的教程让你删这两个文件 —— 删了文件但注册项还在，
   重启后键盘鼠标就全废。要退就卸载，不要删文件。
2. **不要重复安装同一个驱动**。程序里已经做了拦截（驱动在系统里时安装入口不会出现），
   但如果用第三方工具（KeyboardSplitter 之类）再装一遍，可能在过滤链上留下重复项。
3. **删程序目录 ≠ 卸载驱动**。不再用了先进菜单卸载，再删目录。
4. **升级程序前**，如果正在用 Interception 注入，不用动它 —— 新版认得出已装的驱动，
   不会重装。只有杀软把 `interception.dll` 隔离了，才会提示补回库文件（不会重装驱动）。
