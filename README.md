# 衍天高手 The Celestial Diviner

剑网三 PVE 按键辅助工具：把任意键盘键、鼠标键或滚轮变成"按住即连点"或"一键开关"的连发键。
绿色免安装，无需安装任何运行时（Win10 1903+ / Win11 系统自带），需以管理员身份运行。

> **⚠️ 使用范围声明**：本软件**仅供剑网三 PVE 环境下的按键辅助使用**，
> **请勿用于 PVP（竞技 / 名剑大会等）等任何违反游戏规则的违规环境**。
> 在违规环境中使用可能违反游戏用户协议、导致游戏账号受到处罚，
> 由此产生的一切后果由使用者自行承担。

## 下载与运行

1. 从 [Gitee Release](https://gitee.com/sofqi/The-Celestial-Diviner/releases/latest) 或
   [GitHub Releases](https://github.com/Dyse-Sofqi/The-Celestial-Diviner/releases) 下载
   `TheCelestialDiviner-vX-win64.zip`，解压到任意目录（解压得到一个同名文件夹）
2. 右键 `TheCelestialDiviner.exe` → **以管理员身份运行**
3. 首次运行若被 SmartScreen / 杀毒软件拦截，见下方[白名单指引](#杀毒软件--smartscreen-白名单指引)

## 注意事项

- **仅限剑网三 PVE 环境**：本软件只作为剑网三 PVE 环境下的按键辅助使用，**请勿用于
  PVP 等违规环境**——违规使用可能违反游戏用户协议、导致游戏账号受到处罚，后果自负
- **必须以管理员身份运行**：全局按键监听与向游戏窗口模拟按键都要求管理员权限，
  否则监听装不上、注入失效（程序会在状态栏与日志中提示）
- **杀毒软件 / SmartScreen 可能误报**：全局钩子 + 按键模拟属于自动化工具的常规技术手段，
  拦截是行为特征触发的通用规则，并非病毒（白名单方法见下文）
- **DD 驱动是默认注入路线**：键盘连发在多数游戏中需要物理级注入，默认走 DD 驱动
  （闭源组件，安装包不内置）；首次使用 DD 模式时按程序引导一键获取即可，
  官方渠道网络不稳定，下载失败会自动重试直至成功
  （见 [DD 驱动模式](#dd-驱动模式游戏兼容性最强默认启用)）。
  不想用闭源驱动可改走开源的 Interception（装完需重启，见
  [Interception 驱动模式](#interception-驱动模式开源物理级路线可选)）
- **部分游戏过滤模拟按键**：这类游戏的战斗输入直读硬件级输入流，普通注入会被拦；
  请使用 DD 驱动模式（见[常见问题](#常见问题)）。鼠标与滚轮连发不受影响
- **配置不会丢失**：方案、热键、音量等全部存于 `%APPDATA%\TheCelestialDiviner\config.json`
  （安装目录之外），升级 / 重启自动保留
- **联网说明**：仅 DD 驱动授权校验 / 获取、Interception 驱动获取、启动时同步公告、检查更新需要网络，
  其余功能完全本地运行
- **关闭窗口 = 驻留托盘**，不会退出；请从托盘右键菜单退出

## 功能一览

- **连发绑定**：键盘、鼠标 7 键、滚轮均可作为触发键，绑定任意目标键
- **两种触发方式**：开关（按一下开始、再按停止）/ 按压（按住连发、松开即停）；
  开关模式另有**轮转**（同组互斥）与**双宏**（两键轮流触发）
- **节奏可调**：内置常规 / 极限两档连发时序，也支持逐键微调间隔与按压时长
- **四组方案档位 ①②③④**：不同游戏 / 场景各配一组，一键切换；支持自定义
  "切换方案热键"循环切换，切换时播报语音、屏幕键帽闪现目标档位名称（自定义名生效）
- **总开关**：默认 F9，一键启停全部方案；开启 / 关闭有语音播报
  （另可选"衍天高手"专属启动语音）
- **键帽可视化**：按键时屏幕右下角实时显示键帽动画与连击数；
  支持三种显示范围、多套配色、单键隐藏与任意调整位置
- **状态提醒**：可在键帽区常驻一个应用图标键帽，提示总开关当前开启，连发期间自动让位
- **提示语音音量**可调（0~100，默认 70）
- **提示语音可换**：底栏「语音设置」为总开关开启 / 关闭与方案切换分别选择音频——下拉列表
  收录内嵌默认音频、**程序目录里的候选音频**（把 mp3 / wav / m4a / aac / wma 放进 exe 同目录即可，
  不集成进程序）与已导入的自定义音频；也可「导入…」任选文件，支持试听与重置
- **自动更新**：内置"检查更新"，确认后自动下载覆盖安装并重启，配置不丢失
- **方案定制**（「选项」首项）：四个方案档位可命名，并各自绑定主题预设（默认主题 / 衍天高手 /
  莫问高手）；绑定「默认主题」的档位还可定制**应用图标**（33 个可选图标）、**应用名**（窗口名，
  版本号不变）、**键帽配色**与**开关 / 按压 / 双宏三种配色**——切换档位即整套换肤
  （配色、标题与图标、任务栏 / 托盘图标、注释区公告、键帽配色）
- **日间 / 夜间主题**：一键切换，也可跟随系统
- **方案导入 / 导出**：按档位导出 JSON 分享或备份

## 使用说明

1. 点击底部「从左侧键盘管理方案」进入管理模式：
   - 键盘键：直接按一下即添加为连发键
   - 鼠标 / 滚轮：左键点击对应图块添加；右键点击图块删除该键方案
   - Esc 或点击空白处退出管理模式
2. 底部方案面板选择触发方式（开关 / 按压；开关可选常规 / 轮转 / 双宏分组），
   列表行内直接修改间隔与按压时长、勾选启用 / 停用、删除方案
3. 总开关键默认 **F9**，无需设置即可用（可在方案面板顶部更换或清除）；
   需要的话在方案面板顶部设置"切换方案热键"
4. 按 F9 开启总开关（"启动"语音）→ 按下绑定的触发键即开始连发，再按 F9 全部停止
5. 切换档位：直接点选 ①②③④，或按下切换方案热键循环切换（空档位自动跳过）；
   想给档位改名或换一套外观：**「选项」→ 方案定制**（命名 + 绑定主题 + 定制图标 / 应用名 / 配色）
6. 关闭窗口驻留托盘；托盘右键：显示主界面 / 总开关开启关闭 / 退出；双击托盘图标显示 / 隐藏

### 触发方式速查

| 方式 | 行为 |
|---|---|
| 开关 | 按一下启动连发，再按一下停止 |
| 按压 | 按住才连发，松开即停 |
| 轮转开关 | 同分组内互斥：开启一个自动停止组内其他开关 |
| 双宏开关 | 绑定两个键轮流触发（1-2-1-2…），按头键开始 / 再按一起停止 |
| 混合规则 | 任一"按压"键连发中，所有"开关"键自动暂停；全部松开后恢复 |
| 滚轮触发 | 每滚动一格触发一次（按压 = 单发，开关 = 翻转） |

### 键盘注入模式

**首次启动会按系统环境给一次建议**（系统版本 + 内核完整性开关 + 键盘栈上已有的过滤驱动），
推荐该用哪条注入路线，也可以自己改选；之后随时可在菜单里热切换（配置自动保存）：

| 注入模式 | 适用场景 |
|---|---|
| 普通（SendInput） | 兼容面最广，极少数游戏会过滤 |
| 扫描码（DirectInput） | 个别只认扫描码的老游戏 |
| 消息（PostMessage） | 直投窗口消息，仅部分程序有效 |
| **DD 驱动（默认）** | 虚拟物理键盘，游戏兼容性最强 |
| Interception 驱动（物理级 / 开源） | 第二条物理级路线：开源驱动，无反作弊注入标记；装完需重启 |

> 两条物理级路线（DD / Interception）**在系统层互斥**：DD 免重启、开箱即用；
> Interception 是开源驱动（可核对来源与签名）、不依赖 DD 的在线授权，代价是安装后必须重启。
> **注意**：Interception 装上后，DD 的虚拟设备注入会完全失效（实测按键进不了系统），
> 要回到 DD 必须先卸载 Interception 并重启 —— 详见下节。

## DD 驱动模式（游戏兼容性最强，默认启用）

**本软件的键盘连发功能完全依赖 DD 驱动运作**——未安装驱动时连发可能被多数游戏
过滤而无效，请务必按引导完成驱动获取。

DD 驱动虽由作者免费提供，但它是**闭源软件，我们无权将其打包分发**，
所以驱动获取这一步需要由您来完成：**安装包不内置**——首次使用 DD 模式时
程序会自动检测并询问，确认后一键从 DD 官方发布渠道自动下载安装
（约 3.7MB，仅首次），就绪后自动启用，全程无需手动操作；
期间注入自动以普通模式工作，不影响使用。
官方渠道（GitHub）网络不稳定，**下载失败会自动重试直至成功**，请保持网络可用。

也可以选择手动：从 [ddxoft 官网](http://www.ddxoft.com/) 获取驱动，把 **64 位（x64）版**
`dd63330.dll` 放到程序目录（或 `%APPDATA%\TheCelestialDiviner\drivers\`）后重启程序。

- **必须是 64 位（x64）版本**：DD 官方按位数分开发布，32 位那份放进本程序（64 位进程）
  会在加载时直接失败（`LoadLibrary` 错误 193），表现就是"文件放进去了，DD 模式还是用不了"。
  官方 2026 x64 版的 `dd63330.dll` 约 3.7 MB；位数不对时程序会在左下注释区明确提示
  "是 32 位 DLL，无法加载"，不会再静默失败
- 放好文件后不必重装：重启程序，或直接在「选项 → 键盘注入」里再点一次 DD 驱动模式即可
- 免费版驱动加载时需要**联网授权**，请保持网络可用
- 若杀毒软件把驱动 DLL 隔离，文件会消失——先把程序目录加入白名单再放
- 仅键盘注入走 DD 驱动；鼠标 / 滚轮连发始终走系统注入，不受游戏键盘过滤影响
- 已放置的驱动在升级后自动保留（覆盖安装不会删除）

## Interception 驱动模式（开源物理级路线，可选）

如果你不想依赖闭源的 DD 驱动，或 DD 免费版的在线授权经常失败，可以改用
[Interception](https://github.com/oblitum/Interception)——一个开源的键盘 / 鼠标过滤驱动
（LGPL 3.0，作者 Francisco Lopes，驱动由作者签名并在官方 GitHub Release 发布）。

- **安装（随包自带，无需联网）**：官方 v1.0.1 的 `interception.dll` 与 `install-interception.exe`
  已随程序放在 `interception\` 目录（LGPL 允许再分发），点 `选项 → 键盘注入 →
  安装 Interception 驱动…` 确认后：校验 dll 指纹 → 调**官方安装器** `/install`，秒级完成。
  程序不修改、不重签驱动，也不自己写安装逻辑；只有在随包文件被删掉 / 源码构建时，
  才回退到官方 Release 下载（失败自动重试）
- **装完必须重启**：它装的是系统键盘类过滤驱动，重启后才挂上；重启前选择该模式会明确提示
  "请重启电脑后重试"
- **装了就不等于没装：DD 注入会被它挡住**。实测（DD_btn 初始化成功、DD_key 正常调用，
  但注入的按键一条都进不了系统）——Interception 是键盘类过滤驱动，挂在所有键盘设备上，
  DD 的虚拟键盘也在其中，其注入路径被吞掉。所以两者不是"同时只用一条"，而是
  **装了 Interception 就不能用 DD**：要回 DD 必须先「卸载 Interception 驱动…」并重启。
  在菜单里点 DD 时程序会弹窗询问是否卸载，确认后自动卸载并**记住这次意图** ——
  重启后会自动切回 DD，不需要你再手动选一次。
- **切回普通 / 扫描码 / 消息模式不需要重启**：这三条走 SendInput / PostMessage，不碰键盘栈，
  与 Interception 共存没有影响
- **可能被内核隔离拦下**：开启「内存完整性 / 内核隔离（HVCI）」的系统会拒绝加载该驱动。
  现象是"重启后仍然提示驱动未生效"，此时需要在 Windows 安全中心 → 设备安全性 →
  内核隔离 里关闭内存完整性，再重启
- **只注入、不接管**：程序不注册输入过滤器，物理键盘不经过本程序转发，
  所以程序卡顿 / 崩溃不会影响你正常打字（这也是它与"接管式"注入工具最大的区别）
- **卸载**：菜单里另有「卸载 Interception 驱动…」，调官方安装器 `/uninstall`（卸载后同样需重启），
  不必自己找命令行；安装器副本与校验后的文件暂存在
  `%APPDATA%\TheCelestialDiviner\drivers\interception\`

> 诊断开关：命令行加 `--no-intercept` 可在不加载该驱动的情况下启动（与 `--no-dd` 同用途）。
> 现场排查用 `tools/diag-interception.ps1`（只读）：一次打出库文件指纹 / 签名、键盘类
> UpperFilters、System32 驱动签名、服务状态、`\\.\interception00` 能否打开、HVCI 与 Secure Boot。

## 常见问题

**部分游戏里键盘连发不生效？**
这类游戏的战斗输入直读硬件级输入流，并按"系统注入标记"过滤模拟按键——
普通 / 扫描码 / 消息三种注入都会被拦。请使用默认的 **DD 驱动模式**
（无注入标记，对游戏表现为真实键盘）。鼠标与滚轮连发不受影响。

**手动放了 `dd63330.dll`，DD 模式还是用不了？**
按顺序排查：

1. **位数**：必须是 **64 位（x64）** 版。32 位那份在 64 位进程里加载必失败（错误 193），
   这是"放了没用"最常见的原因（详见 [DD 驱动模式](#dd-驱动模式游戏兼容性最强默认启用)）
2. **位置**：`TheCelestialDiviner.exe` 同级目录，或 `%APPDATA%\TheCelestialDiviner\drivers\`
3. **管理员权限**：DD 首次初始化要注册内核驱动，非管理员会失败
4. **杀毒软件**：驱动 DLL 常被隔离，确认文件还在（可加白名单后重放）
5. 以上都不是：程序会在左下注释区给出具体原因（位数不符 / 加载错误码 / 初始化失败），
   照那句话判断即可，不必猜

**升级会丢失配置吗？**
不会。配置存于 `%APPDATA%\TheCelestialDiviner\config.json`（安装目录之外），
升级 / 重启自动保留；导入导出可按档位备份方案。

**程序需要联网吗？**
仅 DD 驱动授权校验、DD 驱动获取、启动时同步公告、检查更新需要网络；其余完全本地
（Interception 驱动随包内置，安装不需要联网）。
