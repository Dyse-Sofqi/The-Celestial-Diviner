# 衍天高手 The Celestial Diviner

键盘 / 鼠标连发（自动点击）工具：把任意键盘键、鼠标键或滚轮变成"按住即连点"或"一键开关"的连发键。
绿色免安装，无需安装任何运行时（Win10 1903+ / Win11 系统自带），需以管理员身份运行。

## 下载与运行

1. 从 [Gitee Release](https://gitee.com/sofqi/The-Celestial-Diviner/releases/latest) 或
   [GitHub Releases](https://github.com/Dyse-Sofqi/The-Celestial-Diviner/releases) 下载
   `TheCelestialDiviner-vX-win64.zip`，解压到任意目录（解压得到一个同名文件夹）
2. 右键 `TheCelestialDiviner.exe` → **以管理员身份运行**
3. 首次运行若被 SmartScreen / 杀毒软件拦截，见下方[白名单指引](#杀毒软件--smartscreen-白名单指引)

## 注意事项

- **必须以管理员身份运行**：全局按键监听与向游戏窗口模拟按键都要求管理员权限，
  否则监听装不上、注入失效（程序会在状态栏与日志中提示）
- **杀毒软件 / SmartScreen 可能误报**：全局钩子 + 按键模拟属于自动化工具的常规技术手段，
  拦截是行为特征触发的通用规则，并非病毒（白名单方法见下文）
- **DD 驱动引导获取**：DD 驱动为闭源组件，安装包不内置；首次使用 DD 模式时程序会
  询问并一键从官方渠道自动下载安装（约 3.7MB，仅首次），
  见 [DD 驱动模式](#dd-驱动模式游戏兼容性最强默认启用)
- **部分游戏过滤模拟按键**：这类游戏的战斗输入直读硬件级输入流，普通注入会被拦；
  请使用 DD 驱动模式（见[常见问题](#常见问题)）。鼠标与滚轮连发不受影响
- **配置不会丢失**：方案、热键、音量等全部存于 `%APPDATA%\TheCelestialDiviner\config.json`
  （安装目录之外），升级 / 重启自动保留
- **联网说明**：仅 DD 驱动授权校验、启动时同步公告、检查更新三处需要网络，其余功能完全本地运行
- **关闭窗口 = 驻留托盘**，不会退出；请从托盘右键菜单退出

## 功能一览

- **连发绑定**：键盘、鼠标 7 键、滚轮均可作为触发键，绑定任意目标键
- **两种触发方式**：开关（按一下开始、再按停止）/ 按压（按住连发、松开即停）；
  开关模式另有**轮转**（同组互斥）与**双宏**（两键轮流触发）
- **节奏可调**：内置常规 / 极限两档连发时序，也支持逐键微调间隔与按压时长
- **四组方案档位 ①②③④**：不同游戏 / 场景各配一组，一键切换；支持自定义
  "切换方案热键"循环切换，切换时播报语音、屏幕键帽闪现目标档位代号
- **总开关**：默认 F9，一键启停全部方案；开启 / 关闭有语音播报
  （另可选"衍天高手"专属启动语音）
- **键帽可视化**：按键时屏幕右下角实时显示键帽动画与连击数；
  支持三种显示范围、多套配色、单键隐藏与任意调整位置
- **状态提醒**：可在键帽区常驻一个应用图标键帽，提示总开关当前开启，连发期间自动让位
- **提示语音音量**可调（0~100，默认 70）
- **自动更新**：内置"检查更新"，确认后自动下载覆盖安装并重启，配置不丢失
- **日间 / 夜间主题**：一键切换，也可跟随系统
- **方案导入 / 导出**：按档位导出 JSON 分享或备份

## 使用说明

1. 点击底部「从左侧键盘管理方案」进入管理模式：
   - 键盘键：直接按一下即添加为连发键
   - 鼠标 / 滚轮：左键点击对应图块添加；右键点击图块删除该键方案
   - Esc 或点击空白处退出管理模式
2. 底部方案面板选择触发方式（开关 / 按压；开关可选常规 / 轮转 / 双宏分组），
   列表行内直接修改间隔与按压时长、勾选启用 / 停用、删除方案
3. 总开关键默认 **F9**，无需设置即可用（可在方案面板顶部更换或清除）；
   需要的话在方案面板顶部设置"切换方案热键"
4. 按 F9 开启总开关（"启动"语音）→ 按下绑定的触发键即开始连发，再按 F9 全部停止
5. 切换档位：直接点选 ①②③④，或按下切换方案热键循环切换（空档位自动跳过）
6. 关闭窗口驻留托盘；托盘右键：显示主界面 / 总开关开启关闭 / 退出；双击托盘图标显示 / 隐藏

### 触发方式速查

| 方式 | 行为 |
|---|---|
| 开关 | 按一下启动连发，再按一下停止 |
| 按压 | 按住才连发，松开即停 |
| 轮转开关 | 同分组内互斥：开启一个自动停止组内其他开关 |
| 双宏开关 | 绑定两个键轮流触发（1-2-1-2…），按头键开始 / 再按一起停止 |
| 混合规则 | 任一"按压"键连发中，所有"开关"键自动暂停；全部松开后恢复 |
| 滚轮触发 | 每滚动一格触发一次（按压 = 单发，开关 = 翻转） |

### 键盘注入模式

「选项」菜单可随时热切换（配置自动保存）：

| 注入模式 | 适用场景 |
|---|---|
| 普通（SendInput） | 兼容面最广，极少数游戏会过滤 |
| 扫描码（DirectInput） | 个别只认扫描码的老游戏 |
| 消息（PostMessage） | 直投窗口消息，仅部分程序有效 |
| **DD 驱动（默认）** | 虚拟物理键盘，游戏兼容性最强 |

## DD 驱动模式（游戏兼容性最强，默认启用）

DD 驱动为闭源第三方组件（作者渠道：[ddxoft 官网](http://www.ddxoft.com/)），
**安装包不内置**——首次使用 DD 模式时程序会自动检测并询问，
确认后一键从 DD 官方发布渠道自动下载安装（约 3.7MB，仅首次），就绪后自动启用，
全程无需手动操作；期间注入自动以普通模式工作，不影响使用。

也可以选择手动：从 [ddxoft 官网](http://www.ddxoft.com/) 下载驱动，把 `dd63330.dll`
放到程序目录（或 `%APPDATA%\TheCelestialDiviner\drivers\`）后重启程序。

- 免费版驱动加载时需要**联网授权**，请保持网络可用
- 仅键盘注入走 DD 驱动；鼠标 / 滚轮连发始终走系统注入，不受游戏键盘过滤影响
- 已放置的驱动在升级后自动保留（覆盖安装不会删除）

  未发现更新或网络不可用时以消息框提示

## 杀毒软件 / SmartScreen 白名单指引

- **SmartScreen**：首次运行弹出"已保护你的电脑"→"更多信息"→"仍要运行"

- **第三方杀软**（火绒 / 360 / 腾讯管家等）：在拦截提示中选择"信任本程序"，
  或把程序目录加入白名单
- 程序绿色免安装：不写注册表、不驻留服务；联网仅限 DD 驱动获取 / DD 授权 / 公告同步 / 检查更新

## 常见问题

**部分游戏里键盘连发不生效？**
这类游戏的战斗输入直读硬件级输入流，并按"系统注入标记"过滤模拟按键——
普通 / 扫描码 / 消息三种注入都会被拦。请使用默认的 **DD 驱动模式**
（无注入标记，对游戏表现为真实键盘）。鼠标与滚轮连发不受影响。

**升级会丢失配置吗？**
不会。配置存于 `%APPDATA%\TheCelestialDiviner\config.json`（安装目录之外），
升级 / 重启自动保留；导入导出可按档位备份方案。

**程序需要联网吗？**
仅 DD 驱动授权校验、启动时同步公告、检查更新三处；其余完全本地。
