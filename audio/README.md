# 候选提示音（散装音频，不入库、不内嵌进程序）

把任意音频文件放进本目录（或在开发机 / 安装目录里直接放到 exe 同目录），构建时会被**原样拷到程序目录**
（与 `TheCelestialDiviner.exe` 同级），启动后在 **「语音设置」** 的下拉列表里即可选择：

- 支持格式：`mp3` / `wav` / `m4a` / `aac` / `wma`（与「导入…」的过滤器一致）
- 选择某个候选音频 = 与手动「导入…」完全同效：复制到
  `%APPDATA%\TheCelestialDiviner\sounds\` 并立即生效，落盘后离线 / 重启仍生效
- 文件本身**不内嵌进 exe**：用户可随时增删替换；删除文件后已导入的语音仍可用（已复制到语音目录）
- 也可直接在**已安装的程序目录**里放音频（无需重新构建）：程序启动时会重新扫描

> 本目录内容被 `.gitignore` 忽略（`audio/*`，仅保留本说明）：
> 音频按「不集成进程序」的方式以**散装文件**随发布包分发（构建 / 发布时拷到程序目录），
> 不入库以免仓库体积无谓增大；仓库根的其他资源（Notice.md 等）不受影响。
